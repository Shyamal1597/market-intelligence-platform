# Smart Money Fusion Widget — Design Document

**Date:** 2026-04-06
**Status:** Approved
**Scope:** Internal dashboard widget for Sunidhi Capital research team

---

## Overview

An AI-powered widget on the main dashboard that fuses four SEBI/NSE public data streams for any stock and produces a single "smart money signal" in plain English — a scorecard plus a 3-sentence narrative synthesis generated by a local Ollama LLM.

---

## Placement

Dashboard page (`app/page.tsx`), directly below the market metrics widget.

---

## Data Streams

| Stream | Source | Already Built? |
|--------|--------|---------------|
| Bulk / Block Deals | NSE snapshot endpoint (existing `/api/deals`) | Yes |
| BSE Announcements | BSE XML feed (existing `/api/filings`) | Yes |
| FII / DII Sectoral Flows | `data/fii-dii-history.json` | Yes (partial) |
| SEBI PIT Insider Disclosures | BSE India PIT HTML/XML, scraped with cheerio | No — new |

Derivatives / F&O data is **excluded** from this widget (reserved for a separate project).

---

## Architecture

```
Dashboard page
  └── SmartMoneyWidget (new component)
        ├── Watchlist feed  ← reads data/smart-money-cache.json
        └── Symbol search   → on-demand query

/api/smart-money/[symbol]          ← new, streams Ollama response via SSE
  ├── parallel fetch:
  │     ├── /api/deals?tab=bulk&symbol=[symbol]
  │     ├── /api/filings?symbol=[symbol]
  │     ├── lib/fii-dii.ts → fii-dii-history.json (sector lookup)
  │     └── /api/insider/[symbol]  (new)
  ├── compact prompt builder (truncate to ~4k tokens)
  ├── POST http://localhost:11434/api/generate (stream: true)
  └── write result to data/smart-money-cache.json on completion

/api/insider/[symbol]              ← new
  └── cheerio scrape BSE PIT page → filter by symbol → return last 3 disclosures
      { name, role, sharesTransacted, transactionType, date }

data/smart-money-cache.json        ← new cache file
  └── { [symbol]: { signal, scorecard, citations, generatedAt } }
```

## Data Payload Per Symbol (prompt input)

To stay within llama3.1:8b's 8k context, each stream is compressed:

| Stream | What we pull | Compressed to |
|--------|-------------|---------------|
| Bulk/Block deals | Last 7 days, this symbol only | Max 5 rows: date, client, side, qty, value |
| BSE announcements | Last 10 filings for this symbol | Title + date only, no body text |
| FII/DII flows | Sector-level, last 5 trading days | Net buy/sell in Cr per day |
| SEBI PIT insider | Last 3 disclosures | Name, role, shares, transaction type, date |

Target prompt token budget: ~4k tokens input, leaving ~4k for response.

---

## LLM Configuration

- **Model:** `llama3.1:8b` via Ollama
- **Endpoint:** `http://localhost:11434/api/generate` (same machine as Next.js)
- **Mode:** Streaming (`stream: true`) — response piped to client via SSE
- **Temperature:** 0.3 (factual, low creativity)
- **No external API calls** — fully on-premises

## Prompt

```
You are a senior equity analyst assistant for Sunidhi Capital, an Indian research firm.

Synthesise the market intelligence below for [SYMBOL] ([COMPANY_NAME])
into a Smart Money Signal report.

RULES:
- Only use the data provided. Never invent figures, names, or events.
- If a stream has no data, mark it "—" and exclude it from the verdict.
- Be specific: name entities, cite rupee figures, reference dates from the data.
- Convergence across streams = stronger signal. Flag divergence explicitly.

OUTPUT FORMAT (follow exactly):

## Stream Scorecard
| Stream            | Signal   | Key Fact |
|-------------------|----------|----------|
| Insider Activity  | 🟢 Bullish / 🔴 Bearish / ⚪ Neutral / — | [one fact with figure] |
| Bulk/Block Deals  | ...      | ...      |
| FII/DII Flows     | ...      | ...      |
| BSE Announcements | ...      | ...      |

## Smart Money Signal
Write exactly 3 sentences:

Sentence 1 — LEAD: Who is the dominant actor and what are they doing?
  Name figures. Be specific.

Sentence 2 — CONNECT: What does a second stream confirm or contradict?
  If streams conflict, say so plainly — do not paper over divergence.

Sentence 3 — IMPLICATION: What does this combination suggest directionally?
  Do not hedge with "may" or "could" unless Confidence is LOW.

Write as if briefing a portfolio manager verbally. No jargon. No bullet
points inside this section.

## Confidence: HIGH / MEDIUM / LOW
[HIGH = 3+ streams agree | MEDIUM = 2 streams agree or thin data |
LOW = streams conflict or data sparse]
Reason: [one sentence]

--- MARKET DATA ---
[compact JSON block]
--- END ---
```

## Widget UX

### Watchlist Feed (default state)
- Displays signal cards for stocks in the existing watchlist (`data/watchlist.json`)
- Cards load **sequentially** — one at a time to avoid hammering Ollama with parallel requests
- Each card shows:
  - Symbol + company name
  - Scorecard table (4 rows, compact)
  - 3-sentence narrative
  - Confidence badge: HIGH (teal) · MEDIUM (amber) · LOW (danger)
  - `as of` timestamp
- Cache stale threshold: **4 hours** — shows refresh prompt, does not auto-regenerate

### On-demand Search
- Text input at top of widget: "Analyse any symbol →"
- Analyst types symbol, hits Enter → card appears at top, streams in
- Result added to cache but not permanently to the watchlist feed

### Loading State (two-phase)
1. **Phase 1 (~1s):** Raw data fetched from 4 streams → scorecard table renders immediately with actual data
2. **Phase 2 (~5–10s):** Ollama streams narrative token-by-token below the scorecard — analyst sees a cursor then text appearing

This means the analyst gets actionable data in ~1 second, narrative is a bonus that fills in.
